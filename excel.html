Exercise 2 · Excel · 15 minutes

Find launch blockers in a register

Add a review skill, then ask Copilot to review the register. Copilot builds a launch review with formulas you can inspect.

Start the steps Get the files

What you will create

  • A Launch review sheet dated 30 September 2026
  • Counts of total, blocked and overdue items
  • A filterable table linked to the source register
  • A short note on what blocks launch

Watch first

1:46 introduction from the real Excel run. The video has captions on screen and no sound.

Get the exercise files

Use the workbook for the exercise. Excel reads skills from a folder, so unzip the skill package first.

ERGO-Skill-Launch-Before.xlsx24-item pilot register ergo-launch-review.zipUnzip to get the skill folder
Prepare: upload the workbook to your OneDrive and open it in Excel for the web. Unzip the skill package on your computer. You should have a folder named ergo-launch-review containing SKILL.md.

Step by step

Open custom skills

  1. Open the workbook and select Copilot.
  2. Select … (Settings and more), then Manage plugins & skills.
  3. Select Custom skills, then Add.
  4. Select Add in OneDrive.

In this Excel version, Add offered only the OneDrive option. If you see Create skills folder, select it first.

Add the skill folder

  1. Excel opens your OneDrive skills folder.
  2. Select Create or upload, then Folder upload.
  3. Choose the unzipped ergo-launch-review folder.
  4. Return to Excel and select Refresh in Custom skills.
Upload the folder, not the ZIP. The folder name must match the skill name.

Read what the skill tells Copilot

Open SKILL.md inside the folder. The top lines tell Copilot when to use it: launch-readiness reviews, overdue action checks or owner-and-dependency reviews.

The numbered rules describe the method, for example:

  • Use the register’s 30 September snapshot, not today’s date
  • Count blocked and overdue items separately
  • Use inspectable formulas and keep the source unchanged

Ask normally

Go back to the workbook. In Copilot, type this request without selecting or naming the skill:

Review this register for launch readiness.

Copilot validates the 24 records, then builds the review. This can take a minute or two.

Ask which skill was used

Which custom skill did you use?

In the rehearsal, Copilot answered ergo-launch-review.

Check the launch review

Open the new Launch review sheet. You should see:

Inspect the formula

Select the Overdue actions count and look at the formula bar. It counts open actions whose due date is before the snapshot date.

Then ask:

Why aren't all blocked items overdue?

Discuss as a leader

  • Which overdue action would you escalate first, and to whom?
  • Why is “blocked” different from “overdue”?
  • Which recurring check in your own area should always follow the same rules?

If something does not work

The skill does not appear in Excel

Check that you uploaded the unzipped folder and that it contains SKILL.md. Then select Refresh in Custom skills.

Copilot gives a general answer instead of a Launch review sheet

Start a new chat and ask again. As a fallback, type @ergo-launch-review Review this register for launch readiness.

The counts differ from the table above

Check the reporting date in cell B2. The exercise uses the register’s snapshot date, 30 September 2026, not today’s date.

The workbook already has a Launch review sheet

Use a fresh copy of the practice workbook so everyone starts from the same register.
