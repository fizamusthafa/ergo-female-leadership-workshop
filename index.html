ERGO Female Leadership Workshop

Turn a repeatable review into a Copilot skill. Then ask in plain language and let Copilot apply your method.

What you will practise

  • Add a custom skill and read what it tells Copilot to do
  • Ask for the task normally, without naming the skill
  • Check that Copilot produced the result you expected
  • Decide what still needs human judgement

Open Excel exercise

1. Save the method

A skill is a short set of instructions: when to use it, what steps to follow and what the result must include.

2. Ask naturally

You do not need a long prompt. A normal request such as “Do a committee readiness check” is enough.

3. Review the result

Copilot prepares a consistent first draft. You still check the facts, assumptions and final decision.

Before you start

You need

  • The exercise file and skill package from the exercise page
  • Permission to edit the file you open
